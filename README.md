# Задание 2 — API-пайплайн

## Описание задачи
Классификация отзывов о мобильных телефонах с помощью LLM через API. 
- Читает отзывы из CSV-файла
- Отправляет их в языковую модель (Qwen-2.5-72b через OpenRouter)
- Получает структурированный JSON с тональностью (positive/negative/neutral) и темой отзыва
- Сохраняет результат в файл в `result.json`

### Датасет
Датасет представляет собой csv файл с отзывами на телефоны (отзовы написаны на русском языке). Данные взяты из открытого источника https://www.kaggle.com/datasets/theovall/phonereviews.
Для задачи данные были сокращены до 500 строк. 
- **Колонки:** 
  - `reviewText` — текст отзыва на английском
  - `rating` — оценка от 1 до 5 (не используется в промпте)

**Важно:** Рейтинг отзыва (1–5) не передаётся в LLM — модель анализирует только текст. Рейтинг используется постфактум для валидации качества классификации.

## Инструкция
### 1. Установка зависимостей
Откройте терминал в папке с проектом и выполните
```
pip install openai pandas python-dotenv
```
### 2. Настройка API-ключа
1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai). (есть лимит по количествк токенов)
2. Перейдите по GET API KAY в личный кабинет.
3. Нажмите **Create Key**, дайте ключу любое имя и скопируйте полученное значение.
4. Откройте файл `.env` в текстовом редакторе и вставьте ваш ключ:
   ```env
   API_KEY=ваш ключ сюда
   API_BASE_URL=https://openrouter.ai/api/v1
   MODEL_NAME=mistralai/mistral-7b-instruct:free
### 3. Запуск скрипт
Запустите скрипт Analiz_otzeuvov.py в любом удомном для вас месте
